# Music: score, playback and the Music Forge

Status: SPEC 2026-10-13 (JS: "add more music and song"; "it was always the same song", "it sounds AI generated").
Today: 2 loops from `tools/generate_sfx.gd` (`music_match` 48 s, `music_menu` 40 s, pad + drone + arpeggio), one player
per level in `GameAudio`; the main menu has no GameAudio, so menu music never plays. All music stays **generated by
code** (no samples, no downloads, no tune from an existing work). Sung lyrics: out of scope.

## 1. Composition rules (the bar every track must clear)
1. **Real composition**: a named motif, a chord progression, A / B / bridge sections over 1:30-2:40. No ambient drone + arpeggio loop.
2. **Instruments that sound played** (recipes in 3): plucks, bowed strings, brass, flutes, reeds, bells, mallets, timpani, drums.
3. **Humanised**: timing jitter, velocity by beat and phrase, delayed vibrato, per-note detune, rendered room reverb.
4. **Every track different**: no two tracks share (lead instrument, mode, tempo +-8 bpm, meter); the forge checks the tuple.
5. **Banned as main voice**: the old pad + arpeggio sound. Pads are support only: pad energy <= 20 % of a track (forge measures it).
6. **One family**: every track quotes the **Call** motif (the God Wizard's theme), changed per kingdom (mode, rhythm, instrument).

**Call** (D Dorian, beats; q = 1): `D4:1 A4:1 G4:.5 F4:.5 E4:1 | D4:1.5 C4:.5 D4:2`. Answer: `F4:1 G4:1 A4:1 C5:1 | B4:1.5 A4:.5 A4:2`.

## 2. Track list (13 tracks + 7 drive stems)
Length = bars x beats-per-bar x 60 / bpm (6/8: bpm = dotted quarter, 2 per bar). Every length is a whole number of samples at 22 050 Hz.
"Drive" = an unpitched percussion stem (same tempo, loops in sync from bar 1) that fades in with combat; harmony-free.

## 3. Instrument recipes (mono, 22 050 Hz)
| Instrument | Recipe |
|---|---|
| Pluck (harp / lute) | Karplus-Strong: delay RATE/f, excitation = noise burst low-passed (brightness 0.3-0.8 by velocity), loss 0.997 harp / 0.990 lute; lute = 2 strings +4 cents, body peaks 110 Hz + 400 Hz; strum = notes 15-30 ms apart |
| Bowed string | 3 band-limited saws +-7 cents, 2-pole low-pass 1.2-3 kHz following the envelope, attack 80-150 ms, release 200 ms, vibrato 5.5 Hz 12-20 cents from 300 ms, bow noise (band-pass 2-4 kHz, -26 dB); section = 3 voices offset 0-10 ms; tremolo = 12 Hz amplitude |
| Brass | 2 saws +-4 cents, filter sweep 400 Hz -> 2.5 kHz in 120 ms, pitch scoop -30 cents -> 0 in 60 ms, vibrato after 400 ms; muted = cutoff max 900 Hz |
| Flute / fife / whistle | sine + 0.15 h2 + 0.05 h3, breath noise band-passed at f (Q 2, -18 dB), 30 ms chiff on attack, vibrato 5 Hz 10 cents after 350 ms; grace notes 40 ms |
| Double reed (shawm) | pulse 30 % duty, low-pass 2.5 kHz, formant peak 1.2 kHz, vibrato 6 Hz 15 cents |
| Bells | glass / celesta: FM ratio 1:3.5 (glass) or 1:4 (celesta), index 3 -> 0.5 over the note, decay 1.2-3 s; tolling / tubular: partials 1, 2.76, 5.4, 8.9 with decays 4 / 2 / 1 / 0.5 s |
| Mallet (log) | partials 1, 3.93, 9.2, decays 0.6 / 0.15 / 0.05 s, 5 ms noise click |
| Timpani / taiko / toms | sine with pitch drop (+3 % timpani, +30 % toms) over 60-80 ms, membrane partials 1.5, 1.98, 2.44 (timpani), noise strike 10 ms, decay 0.3-1.5 s |
| Snare / claps / shaker | band-passed noise bursts (snare 1.5-5 kHz 150 ms + 190 Hz body; shaker HP 2 kHz 60 ms; clap = 3 bursts 10 ms apart) |
| Choir (formant) | 5 detuned pulse voices, vibrato 5 Hz 20 cents with random drift, 3 band-pass formants per vowel: ah 730/1090/2440, oh 570/840/2410, oo 300/870/2240 Hz (gains 0 / -6 / -12 dB, widths 80 / 90 / 120 Hz), vowel morph per phrase, attack 200 ms, breath noise |
| Pad (support only) | additive, <= -12 dB under the lead; never carries a melody |

Humanisation: onset jitter gaussian sigma 6 ms (clamp +-15 ms; drums on downbeats +-3 ms); velocity = beat weight
(1.0 / 0.75 / 0.9 / 0.75) x phrase curve (rise to bar 3 of each 4-bar phrase, ease on the last bar) x (1 +-0.06);
detune +-3 cents per note; no two consecutive identical velocities. Tempo is fixed (whole-sample lengths).
Room: Freeverb-style mono reverb (8 combs 558 / 594 / 638 / 678 / 711 / 745 / 778 / 808 samples, 4 all-passes 278 / 220 /
170 / 112, damping 0.4, pre-delay 25 ms, room size and wet per track: 0.6-0.9, -14 to -8 dB). Master: soft limiter, peak <= -1 dBFS.

## 4. When each plays
| Context (`set_music_context`) | Pool / rule |
|---|---|
| `menu` | `theme_main`, loops seamlessly; pause menu = the level's music -6 dB (no switch) |
| `campaign` | `campaign_map`, loops; briefings and story screens; `ep8_choice` / `ep8_credits` -> `chant` |
| `match` (skirmish, layout levels, missions) | own kingdom x2, `field` x1, enemy kingdom x1 (mirror: own + `field`); first track = own kingdom; seeded order, never the same twice in a row; each track plays once, then 8-20 s silence (skipped when intensity >= 0.3), then the next; after 4:00 of intensity < 0.1 the next pick is `tavern` (once per 10 min) |
| missions by episode | own kingdom: Ep1-2 fire; Ep3 shadow; Ep4 nature; Ep5 m1-2 fire, m3-4 shadow; Ep6 m1-2 ice, m3-4 nature; Ep7 ice; Ep8 the chosen wizard. Enemy = the mission's main foe. Optional `MissionConfig.music_tracks` overrides the pool |
| `boss` | `boss` loops while a boss bar shows (or the mission calls it); back to `match` when it ends |
| `wave_strike` | `wave_strike` x2, `field` x1, same gap rules |
| match end | current track fades out 1.0 s, sting plays once, 3 s silence, then `theme_main` at -6 dB on the end screen |

- **No restart**: the same context + kingdoms = nothing happens; F9 restart keeps the current track playing.
- **Cross-fades**: context switch 3 s; track to track inside a pool 2 s (or the gap); sting cuts in after a 1 s fade.
- **Combat intensity** (GameAudio, every 0.5 s): enemy combat units (not workers, critters, caravans) within 20 m of an own
  building or 16 m of the own wizard, `n / 12` clamped; or 0.6 for 4 s after an own building / the wizard takes damage. Rise
  1.5 s, hold 8 s, fall over 12 s. Drive stem: on at 0.3, off below 0.15; volume -18 dB at 0.3 -> 0 dB at 0.75 and above.
  Wave Strike: units within 25 m of the own bastion, or bastion damage.

## 5. Tech rules
- **Music Forge** `tools/music_forge/`: `music_forge.gd` (SceneTree; `-- track=<id>|all`, `-- excerpts`, `-- force`),
  `instruments.gd`, `humanise.gd`, `reverb.gd`, scores as data `tools/music_forge/scores/<id>.json` (meta: bpm, meter, bars,
  key, lead, sections, `excerpt_bar`, seed; voices as `"D4:1 A4:1 G4:.5 | ..."`, chords `"Dm:2 C:2"`, drum patterns).
- Deterministic: seed = score `seed`; same score = same bytes. A track is re-rendered only when its score hash changes.
- Output: 16-bit **mono WAV 22 050 Hz** (Godot cannot write Ogg) in `assets/audio/music/<id>.wav`, drives `<id>_drive.wav`.
  Budget: about **77 MB** for the list above (1 756 s), hard cap 80 MB. Lead: set the WAV importer default to QOA for new
  imports (`project.godot`), so the export is about 1/5 of that.
- Loop seams: render the reverb over two copies of the track and keep the second, wrap note tails to the start;
  |last - first| <= 0.02 and the slope change at the seam <= 0.02. Stings: no loop, fade to < -60 dBFS over the last 50 ms.
- Loudness (Audio Lab music rule): integrated -12 +-1.5 LUFS in the file (MUSIC_DB -10 -> about -22 in game), true peak
  <= -1 dBFS; drives -16 +-2 LUFS. Render time <= 3 min per track on the laptop.
- **MusicDirector** (`scripts/audio/music_director.gd`, `class_name MusicDirector`): a child of `/root` made by
  `static ensure(tree) -> MusicDirector`, so it survives scene changes; called by GameAudio and the main menu. API:
  `set_music_context(context: StringName, kingdom := &"", enemy_kingdom := &"")`, `set_combat_intensity(v: float)`,
  `combat_intensity() -> float`, `play_sting(id: StringName)`, `set_track_pool(ids: Array[StringName])`,
  `current_track() -> StringName`, signal `track_changed(id)`. Players on bus `Music` (main + drive, started on the same
  frame; `AudioStreamSynchronized` if it plays in sync). `GameAudio.set_music("menu" | "match" | "none")` keeps working
  and maps to contexts; missing files fall back to the old `music_match` / `music_menu`, never an error.
